# Athaliana_Natural_Selection_Conflict
The repository contains copies of analyses, as well as trait and climate data associated with Ruffley, Lutz et. al 2024.

AtlasofPhenotypes.rmd contains R code for every analyses and figure references in both the main text of Ruffley, Lutz, et al. 2024, as well as the supplemental text.

The folder `manuscript-2026-resubmission/` contains the 2026 NEE resubmission: the revised main text, supplement, and supplementary tables workbook. Earlier manuscript versions (the 2023 bioRxiv-era PDF and its supplement, previously at the repo root and in `Ruffleyetal2023_old/`) were removed 2026-08-17 and remain available in the git history.
